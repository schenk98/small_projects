MVP skeleton

Čtenářský pas

Sledování čtení a bodů pro žáky a učitele

Projekt je připraven jako Spring Boot + Thymeleaf + PostgreSQL základ pro další MVP kroky.

  • Flyway migrace a schéma dat
  • Doménové entity pro žáky, učitele, knihy a čtenářské session
  • Docker Compose pro lokalní běh s PostgreSQL
  • Připravená základní kontrola přístupu pro web
