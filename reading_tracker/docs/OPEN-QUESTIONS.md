## Backlog 1.0

- Povinná verifikace e-mailu při registraci.
- Reset hesla.
- Upload avatarů (ne jen presety) + moderace nevhodných.
- i18n (složka messages pro další jazyky).
- PWA (instalace, offline — nice to have).
- Seed / demo data pro prezentaci.
- Smoke E2E testy učitelského CRUD.
- Produkční deploy (doména, HTTPS, embedding do webu školy).
