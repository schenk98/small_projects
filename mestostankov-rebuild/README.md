## mestostankov-rebuild

Rebuild of the public website for **Město Staňkov** (`mestostankov.cz`) with a modern stack, while preserving existing URLs as much as possible.

### Repo structure

- `support/`: one-off/support tooling (crawler, scraper, importers, audit scripts)
- `product/`: the actual deliverable (DB/schema, backend, frontend, resources)
- `docs/`: project documentation and decisions
